# BlueHaven Agent Skills

This directory contains repository-local guidance for AI coding and business-support agents.

## Installed skill collections

- `security-audit/` — Cloudflare security-audit workflow.
- `company-values/` — define company values and culture.
- `find-community/` — identify and understand the community to serve.
- `validate-idea/` — test business ideas before building.
- `mvp/` — scope a minimum viable product.
- `processize/` — design a manual-first delivery process.
- `first-customers/` — acquire and learn from early customers.
- `pricing/` — develop pricing and tier strategies.
- `marketing-plan/` — create a sustainable content-led marketing plan.
- `grow-sustainably/` — evaluate profitable and sustainable growth.
- `minimalist-review/` — review decisions through minimalist-business principles.

The ten business skills above are adapted verbatim from the public
[slavingia/skills](https://github.com/slavingia/skills) repository, whose plugin metadata identifies the collection as MIT-licensed and credits Sahil Lavingia.

These files provide instructions to compatible AI agents. They do not add website pages, runtime code, dependencies, or database changes by themselves.
